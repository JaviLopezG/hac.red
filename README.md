# HAC en red (hac.red)

Sitio web estático del colectivo HAC en red (Hackers Activistas de Cantabria).

Página publicada mediante GitHub Pages bajo el dominio `hac.red` con DNS
gestionadas en Cloudflare.

Actualmente sirve como respaldo y difusión de la convocatoria para la 1ª
reunión:

- Debate: "¿Cómo podemos ayudar?"
- Fecha: 2026-12-03 (jueves)
- Hora: 19:00 UTC+1
- Lugar: CSA La Libre (Rampa de Sotileza, Santander)
- Contacto: contacto@hac.red

Incluye enlace de descarga del cartel oficial y de las diferentes variantes del
logotipo del colectivo (`}:`).

## Estructura

- `index.html`: Página principal.
- `styles.css`: Estilos visuales (colores violeta `#865FB3`, morado `#6420B3` y
  blanco `#ffffff`).
- `fonts/`: Tipografía Player Sans (Player Sans Mono 8x13).
- `imagenes/`: Cartel de la reunión y variantes del logo.
- `reunion-1.ics`: Archivo iCalendar para importar el evento.
- `CNAME`: Configuración de dominio personalizado para GitHub Pages.
